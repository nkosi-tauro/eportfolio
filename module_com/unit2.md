## Cloud Adoption in Government: Using ROCCA and TOGAF for Responsible, Sovereign Services

As populations grow and more people come online, government agencies need to be able to deliver reliable digital services to their citizens. This has driven an increase in demand for cloud expertise and solutions architects. Because governments need an auditable standard when implementing services, the ROCCA (Roadmap for Cloud Computing Adoption) model gives institutions a reliable roadmap to follow when adopting cloud services (Anggraini, Binariswanto and Legowo, 2019).


In addition to ROCCA, which sets out an adoption roadmap, governments need a framework for designing and implementing the cloud architecture itself. One such framework is TOGAF, an open standard that provides a general approach to enterprise architecture. Its components include the Architecture Development Method (ADM), which gives detailed guidance on developing architectures such as cloud services, and Architecture Governance, which ensures that appropriate safeguards and oversight are in place (Jager, 2025). Governance is particularly important for government institutions.


Recent geopolitical tensions have highlighted the need for cloud sovereignty. Governments that rely on external cloud services can be susceptible to interference driven by political pressure (Angelier, 2026). This underlines the need for open frameworks such as TOGAF, which can help institutions develop internal skill sets and help local cloud providers meet government security requirements. In turn, this allows governments to adopt the cloud responsibly.
